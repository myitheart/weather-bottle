# Dynamic Pearl V2.3 · Phase 4 桌角工作回顾

工作回顾已接入灵动珠。入口位于光珠快捷面板、Codex 活动面板、专注面板、经典天气瓶盖舱，以及右键与托盘菜单。打开的是复用现有毛玻璃主题的非模态面板。空闲时不启动历史读取进程。

## 使用方式

1. 打开「工作回顾」，在「项目设置」中添加 Codex 实际使用的工作目录。可选多个目录，查询以精确目录为范围。
2. 选择「今天」「昨天」或「近 7 天」，点击「生成回顾」。切换日期时可显示上次完整快照。点击「取消读取」可取消本次生成。
3. 展开事项查看里程碑状态、来源回合、证据与已有线索。项目默认展示两个事项，其余可以展开。选择来源后可打开 Codex 或复制定位信息。打开来源不会清除活动面板的待查看或挂住状态。
4. 选择同项目的两个事项，或选择一条待核对建议，在「纠正」菜单中合并。选中多回合事项中的一个来源回合，可拆为新事项或填写一条有适用范围的用户确认。菜单也支持撤销该项目最近一次纠正。
5. 项目设置可以移出查询范围，也可以经确认清除该目录的快照和纠正。工作回顾的 SQLite 文件位于 `%LOCALAPPDATA%/DynamicBottle/work-memory.sqlite3`。生成并保存时才创建数据库。移出范围保留本机缓存，清除缓存是独立操作。

后台线程通过与 CLI 共用的本机服务生成并保存。取消、切换范围或关闭面板后，迟到的结果不会覆盖当前界面。需要时可用「上次快照」恢复本轮部分读取之前的完整结果。Esc、面板外点击、拖动光珠和收进托盘都能关闭工作回顾。提醒或专注完成时，回顾让位，再打开可继续原来的浏览位置。

本阶段集成规则回顾。Phase 3 的可选 AI 仍使用独立 CLI 的预览与授权流程，界面不发起模型调用。Windows 打开聊天仍受 Codex URL 处理器及聊天可见性影响，复制定位提供聊天与回合 ID 兜底。
