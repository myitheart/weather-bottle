# Dynamic Pearl V2.3 · WM-09 规则版本机验收

**本机规则版通过验收。** 工作回顾仍按授权目录手动生成。重开面板、切换日期或点击「上次快照」时，先复核项目选择和持久化缓存。核对期间隐藏旧树并禁用来源操作。被排除或已清除的目录不会从内存恢复。快照与修订一致时保留原来展开的节点和来源选择。

项目中的「读取范围」分别列出普通聊天、归档聊天的读取条数和完成情况。零条归档表示本次查询无样本，归档覆盖提示继续保留。在测试夹具中模拟归档过程中同一聊天跨两个列表出现，回顾只计一次并标为部分读取。

## 验收记录

验收时间为 2026-11-19，使用 Windows、PySide6 `6.12.0`、Codex Desktop `26.1111.2228.0`、Codex CLI `0.169.0-alpha.11.1`。

| 验收项 | 本机结果与覆盖边界 |
| --- | --- |
| 回归和交互 | 50 项自动测试通过。13 项 QtTest 面板交互分别在 100%、150%、200% 缩放下通过，含项目排除、缓存清除、切日期和重新打开。 |
| 真实历史与权限 | 同一灵动珠工作目录读取 3 条普通聊天、0 条归档，生成 8 个事项。隔离的临时 SQLite 验证了缓存重开、外部排除后立即隐藏树及来源不可操作。 |
| Windows 来源 | 使用实际 Windows Qt 平台，把已由本机 App Server 核对的当前聊天 URI 交给 Windows，系统接受。Codex 窗口中的最终落点尚未验证。 |
| 双屏与托盘 | 在两个真实屏幕上验证了共八个角落的定位，面板几何均位于对应工作区内。系统可用托盘。物理拖动及实际点击托盘图标仍待验收。 |
| 隐私 | 使用规则模式，无模型请求。真实历史仅用于本机验收，产生的快照和排除记录写入临时测试库。 |

复跑命令如下。两次缩放复跑分别设置 `QT_SCALE_FACTOR` 为 `1.5` 和 `2`。

```powershell
.\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tools -p 'test_work_memory*.py' -q
$env:QT_SCALE_FACTOR = '2'
.\.venv\Scripts\python.exe -B -X utf8 -m unittest discover -s tools -p 'test_work_memory_panel.py' -q
```
